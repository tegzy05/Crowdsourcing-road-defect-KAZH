# Народный контроль дефектов платных дорог — демо

Интерактивный прототип: форма для жителей (отправить жалобу на дефект дороги,
с реальной камерой — можно сделать несколько кадров и удалить неудачные)
+ панель для сотрудника КАЖ (просмотр и обработка репортов). Данные хранятся
в `localStorage` браузера — бэкенд не нужен.

## ⚠️ Важно про камеру

Браузеры разрешают доступ к камере (`getUserMedia`) только по **HTTPS** или
на `localhost`. Поэтому:

- при локальном запуске (`npm run dev`) камера работает сразу — Vite
  отдаёт `localhost`;
- если открыть собранный `dist/index.html` просто двойным кликом
  (`file://...`) — камера **не заработает**, это ограничение браузера,
  не баг;
- на GitHub Pages камера будет работать, потому что GitHub Pages отдаёт
  сайт по HTTPS автоматически.

Также при первом открытии страницы браузер спросит разрешение на доступ
к камере — его нужно подтвердить.

## Запуск локально

Нужен [Node.js](https://nodejs.org/) версии 18 или новее.

```bash
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173/` — открой его в браузере.

Отправь жалобу на вкладке «Форма жителя» (нажми «Открыть камеру», сделай
один или несколько кадров, лишние можно удалить крестиком), затем
переключись на «Панель КАЖ» — жалоба появится там вместе с фото.

## Деплой на GitHub Pages (пошагово)

1. Установи [Git](https://git-scm.com/), если его ещё нет, и создай
   пустой репозиторий на [github.com/new](https://github.com/new)
   (например, назови `road-defects-demo`). Не добавляй README/лицензию
   при создании — репозиторий должен быть полностью пустым.

2. В `vite.config.js` замени строку `base: "./"` на:
   ```js
   base: "/road-defects-demo/",
   ```
   (используй точное название своего репозитория вместо
   `road-defects-demo`; если репозиторий называется
   `твой-username.github.io`, оставь `base: "/"` без изменений).

3. В терминале, находясь в папке проекта:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_USERNAME/road-defects-demo.git
   git push -u origin main
   ```

4. Установи пакет для автодеплоя и добавь скрипт:
   ```bash
   npm install --save-dev gh-pages
   ```
   Затем открой `package.json` и в `"scripts"` добавь строку:
   ```json
   "deploy": "npm run build && gh-pages -d dist"
   ```

5. Запусти деплой:
   ```bash
   npm run deploy
   ```
   Эта команда соберёт проект и запушит папку `dist/` в отдельную ветку
   `gh-pages`.

6. На GitHub открой репозиторий → **Settings → Pages** → в разделе
   "Build and deployment" выбери **Source: Deploy from a branch**,
   ветку **gh-pages**, папку **/ (root)**, нажми **Save**.

7. Через 1–2 минуты сайт будет доступен по адресу:
   ```
   https://ТВОЙ_USERNAME.github.io/road-defects-demo/
   ```
   Это уже HTTPS-ссылка — камера будет работать.

Если что-то не получится на любом из шагов — пришли текст ошибки, разберём.

## Сборка для продакшена (без GitHub Pages)

```bash
npm run build
```

Готовые файлы появятся в `dist/` — их можно загрузить на любой статический
HTTPS-хостинг (Netlify, Vercel, Cloudflare Pages и т.д. — там деплой ещё
проще: просто перетащить папку `dist` в браузере на сайте хостинга).

## Важно про хранение данных

Это демо-версия: данные лежат в `localStorage` браузера, то есть видны
только на том устройстве и в том браузере, где были введены — жалоба,
отправленная с телефона, не попадёт в панель КАЖ, открытую на другом
компьютере.

Для реального пилота (чтобы форма жителя и панель КАЖ работали на разных
устройствах одновременно) нужен настоящий бэкенд с базой данных — например
Firebase (Firestore) или Supabase. Дай знать, если нужно подготовить такую
версию.
